# IoT 通信契约 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付可独立验证的 PLC 子设备配置及九类 MQTT 消息契约。

**Architecture:** JSON Schema Draft 2020-12 为结构事实源；Python 参考校验器处理严格 JSON 解码、身份和跨字段语义。固定样例及真实校验测试不依赖 Hub 或 Broker。

**Tech Stack:** Python 3.12 开发校验环境、jsonschema 4.25.1、标准库 unittest；不指定未来 PLC Agent 运行依赖版本。

**Spec:** `doc/初始技术设计.md`、`doc/IoT采集执行设计.md`。

## Global Constraints

- 配置属于 PLC 子设备，按 PLC 汇总完整快照；Hub 最后对接。
- MVP protocol 只允许 `modbus_tcp`。
- 未知字段拒绝；禁用项仍校验；坏质量 value=null。
- 配置最多 2 MiB、50 子设备、2000 总点；遥测最多 128 KiB、500 点/批。
- 不执行 MQTT、设备连接、数据库或 Hub 变更。
- 目录非 Git 仓库，不初始化仓库，不创建 worktree 或提交。
