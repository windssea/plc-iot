# 配置核心与持久化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 实现可独立测试的不可变配置模型、候选/提交状态及 SQLite 重启恢复。

**Architecture:** 复用阶段 A 的唯一契约校验器；ConfigSnapshot 表达不可变配置，ConfigStore 使用显式事务保存完整快照、活动指针及请求结果。prepare 不应用设备配置，commit 必须由后续执行协调器在本地启动成功后调用。

**Tech Stack:** Python 3.12、dataclasses、sqlite3、现有 jsonschema、unittest。

**Spec:** `doc/初始技术设计.md` 第 7/9 节、`doc/IoT采集执行设计.md` 第 6 节。

## Global Constraints

- PLC 子设备配置按 PLC 整体提交；错误配置不能改变已提交活动版本。
- 同版本同内容幂等，不同内容拒绝，低于活动版本拒绝；回滚内容用更高新版本。
- 原始消息格式、未知字段、跨字段校验沿用阶段 A。
- 本阶段不连接 MQTT、现场设备、Hub，不发送真实 APPLIED ACK。
- 本地目录不是 Git 仓库；按源目录运行，打包/容器发布另行实现。

## Task 1: 配置模型和校验归入核心

Interfaces: `ConfigSnapshot.parse(payload: bytes, gateway_id: str) -> ConfigSnapshot`；拒绝时抛 `ConfigValidationError(issues)`；`content_json` 为稳定排序的业务内容，不含 messageId/timestamp/version。

- [x] 先测非法配置被拒绝、模型不可变、ID 排序/数值等价不造成内容冲突。
- [x] 将既有校验器迁移到核心包，tools 保留兼容导入；保证原测试持续通过。
- [x] 使用 frozen dataclass + tuple 构建 PLC/Device/Point/Connection/Report 模型，明确不支持运行期间修改共享字典。

核心测试行为：

```python
snapshot = ConfigSnapshot.parse(payload, "PLC-01")
self.assertEqual(snapshot.devices[0].points[0].point_id, "voltage")
with self.assertRaises(FrozenInstanceError):
    snapshot.devices[0].enabled = False
```

## Task 2: SQLite 候选和提交

Files: `src/plcnext_iot/config/store.py`、`src/plcnext_iot/config/locking.py`、`tests/test_config_store.py`。

Interfaces: `ConfigStore(path, gateway_id)` context manager；`prepare(payload) -> PrepareResult`（PREPARED/APPLIED/REJECTED）；`commit(token) -> ConfigSnapshot`；`fail(token) -> None`；`load_active() -> ConfigSnapshot | None`。

- [x] 测新库无活动配置、prepare 后仍无活动配置、commit 后重开恢复。
- [x] 测低版本、同版冲突、重复提交、失败重试、旧 token、另一 PLC、同时打开两个 store。
- [x] 实现 OS 文件锁、SQLite application_id/user_version、WAL/FULL、BEGIN IMMEDIATE 和外键。
- [x] 提交时同一事务写活动/前一版本指针及请求结果；失败只更新候选，不改旧指针。
- [x] 重开将未提交候选标为 INTERRUPTED，活动版本不变；相同内容允许重新准备。

关键测试行为：

```python
candidate = store.prepare(payload)
self.assertIsNone(store.load_active())
store.commit(candidate.token)
self.assertEqual(store.load_active().config_version, 10)
```
